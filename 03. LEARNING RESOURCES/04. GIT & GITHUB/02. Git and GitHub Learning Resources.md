# Recommended DevOps Learning Order

You do not need to complete all 20 resources before moving forward.

For DEVOPS-WORLD, I recommend:

1. Learn what version control is.
2. Understand Git versus GitHub.
3. Complete the freeCodeCamp Git and GitHub course.
4. Read the relevant beginner chapters of Pro Git.
5. Practice with GitHub Skills.
6. Practice branching with Learn Git Branching.
7. Create repositories entirely from the terminal.
8. Practice branches and merges.
9. Intentionally create and resolve merge conflicts.
10. Learn fetch, pull, and push properly.
11. Learn reset, restore, and revert.
12. Learn stash.
13. Learn rebase.
14. Learn reflog and recovery.
15. Practice pull requests and code reviews.
16. Learn tags and releases.
17. Learn repository protection and permissions.
18. Learn GitHub CLI.
19. Learn GitHub Actions fundamentals.
20. Connect Git to CI/CD and GitOps.
